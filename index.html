SELECTED WORKS

代表プロジェクト

医学・教育・人材支援の課題を、AIとWeb技術で具体的なワークフローへ変換。

01 MG中心プロトタイプ

DigiNeuro Marker

重症筋無力症などの神経疾患で、診察時だけでは捉えにくい症状変化を自宅で記録し、経時比較を支援するWebアプリ。眼瞼下垂、上肢、歩行、姿勢、表情、音声、ePROを統合。

担当・価値

医学論文を起点に要件化し、患者向け導線、時系列記録、医師共有のダミーフローまで設計・実装。診断機器ではなく、変化の記録・比較支援として位置づけ。

TECH: React Vite MediaPipe Face・Pose IndexedDB Recharts GitHub Pages
02 デモSPA／実運用ロジック応用

Career Karte Assistant

人材支援企業で実運用されるAI問診ロジックを応用し、面談前準備からSHIRP形式のキャリアカルテ作成、権限別閲覧まで支援するエージェントUI。企業名・内部情報は非公開。

担当・価値

初回／継続面談、AI対話、カルテ更新、一般ユーザー・企業管理者・運用管理者・コンサルタント別画面を設計。PDF／CSV出力にも対応する構成。

TECH: React TypeScript Chakra UI OpenAI・Gemini API Three.js・VRM GitHub Pages
03 Medteriaインターン／企画リード経験

AI解説生成システム

医学部の過去問PDF・画像から、生成AIで解答・解説を作成しPDFとして提供する学習支援基盤。大学ごとの教材作成コストを下げる企画として、設計・検証を推進。

担当・価値

FastAPIの非同期ジョブ、Geminiによるマルチモーダル生成、Markdown→PDF変換を構成。GitHubとVanilla JSの簡易アプリを使い、企画立ち上げ・開発指導も経験。

TECH: Python 3.13 FastAPI Gemini Uvicorn Pandoc GitHub Vanilla JS

AWARD & RECOGNITION

優秀賞 最高評価 賞金30万円

HEALTH AI

Photo Carb Counter

食品写真と手を参照し、炭水化物量を参考推定。MediaPipe Hands、Gemini、FNDDS＋日本食品標準成分表の計7,970件を統合。
